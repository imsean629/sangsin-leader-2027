# 리더십 테스트 — 관리자 데이터 가이드

「함께 일할 때, 나는 어떤 리더일까?」(26/27년 경영검토회)의 응답을 모으고 내려받는 방법입니다.

## 1. 무엇이 저장되나

결과 카드가 공개되는 순간 한 건이 기록됩니다.

| 항목 | 내용 |
|---|---|
| ts | 기록 시각 (ISO, UTC) |
| nickname | 참여자가 입력한 닉네임 (최대 10자) |
| result / resultName | 결과 유형 코드(N·B·S·R·W) / 이름(항해장 등) |
| rule | 결과 결정 방식: single(단독 1위), q8(8번으로 동점 해소), recent(가장 최근 선택으로 해소) |
| q1~q8 | 각 문항에서 고른 보기 글자(A~E) |
| t1~t8 | 각 문항에서 고른 보기의 유형 코드 |
| score_N~score_W | 유형별 보정 점수 (고른 횟수 ÷ 노출 횟수) |
| sid | 한 번의 참여를 구분하는 임의 번호 |
| v | 테스트 버전 |

실명·연락처·기기 정보는 저장하지 않습니다. 닉네임 입력 화면에 "닉네임과 응답이 행사 통계용으로 저장된다"는 안내가 있습니다.

## 2. 운영 방식 두 가지

### A. claude.ai 페이지 그대로 사용 (설정 없음)
- 응답은 이 페이지의 저장소에 **참여자 1명당 1행**으로 기록됩니다. 다시 하면 최신 결과로 갱신됩니다.
- **조건:** 참여자가 claude.ai에 로그인되어 있고, 이 페이지에 대해 **Contributor(참여) 이상 권한**이 있어야 기록됩니다. 로그인하지 않은 사람도 테스트와 카드 저장은 할 수 있지만, 응답은 기록되지 않습니다.
- **내려받기:** 소유자·편집자 계정으로 페이지 주소 끝에 `#admin`을 붙여 엽니다. 유형별 집계와 최근 응답이 보이고, [CSV 내려받기]·[CSV 복사]를 쓸 수 있습니다.
- 사내 전원이 claude.ai 계정을 쓰지 않는다면 B 방식을 권장합니다.

### B. 자체 서버 + Google 시트 (행사장 QR 권장)
1. Google 시트를 새로 만들고 [확장 프로그램 → Apps Script]를 엽니다.
2. `apps_script_Code.gs` 내용을 붙여넣고 저장합니다.
3. [배포 → 새 배포 → 웹 앱]을 선택하고, 실행 계정은 "나", 액세스 권한은 "모든 사용자"로 배포합니다. 웹앱 URL을 복사합니다.
4. `리더십테스트_체험판.html`을 열어 `SHEET_URL: ""`의 따옴표 안에 그 URL을 넣습니다.
5. 이 HTML 파일을 정적 웹 주소(사내 웹서버, GitHub Pages, Netlify 등)에 올립니다. 그 주소로 QR을 만듭니다.
6. 응답이 시트의 '응답' 탭에 한 행씩 쌓입니다. [파일 → 다운로드 → Excel/CSV]로 내보내면 됩니다.

- **조건:** 참여자의 로그인이 필요 없습니다.
- **기록 단위:** 참여 1회당 1행입니다. 같은 참여에서 답을 바꿔 결과를 다시 보면 그 행이 갱신되고, '다시 하기'를 누르면 새 행이 생깁니다.

> claude.ai 페이지 안에서는 보안 정책상 외부 주소로 데이터를 보낼 수 없습니다. 그래서 B 방식은 자체 서버에 올린 파일에서만 작동합니다.

## 3. 활용 예시
- 유형 분포: `result` 열로 피벗 → 조직 전체의 '어려울 때 행동 경향'
- 문항별 선택 분포: `t1`~`t7` 열 → 어떤 상황에서 어떤 행동을 많이 고르는지
- 내년 비교: `v`(버전)를 바꿔 같은 문항을 다시 쓰면 연도별로 비교할 수 있습니다.

결과는 우열 평가가 아니라 행동 경향입니다. 개인 평가나 인사 자료로 쓰지 않는 것을 권장합니다.
